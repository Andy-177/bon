# BON (Binary Object Notation) 协议规范

**版本**: v1.0  
**设计目标**: 轻量级、自描述、支持任意精度的二进制序列化格式

---

## 1. 概述

BON 是一种二进制序列化协议，支持多种数据类型，包括 `null`、布尔、整数（任意精度）、浮点数（双精度）、字符串、二进制数据、数组、对象和高精度小数。所有键值对均采用 TLV（Type-Length-Value）结构，支持嵌套和复杂数据结构。

---

## 2. 整体结构

```
+--------+--------+------------------+
| 魔数    | 类型   | 载荷             |
| (3字节) | (1字节)| (变长)           |
+--------+--------+------------------+
```

### 2.1 魔数 (Magic Number)

- **固定值**: `0x62 0x6F 0x6E` (ASCII: "bon")
- **位置**: 文件/流开头
- **大小**: 3 字节

### 2.2 根类型

- **固定值**: `0x06` (OBJECT)
- **位置**: 魔数之后
- **大小**: 1 字节

### 2.3 载荷

- OBJECT 的完整 TLV 数据（见 3.1）

---

## 3. 数据类型定义

| 类型标记 | 类型名称 | Python 类型 | 长度字段 | 数据大小 | 说明 |
|---------|---------|------------|---------|---------|------|
| `0x00` | NONE | `None` | **无** | 0 | 空值 |
| `0x01` | BOOL | `bool` | **无** | 1 | 布尔值（0x00=false, 0x01=true） |
| `0x02` | NUMBER | `int` | **有 (uint64)** | **变长** | 任意精度整数（小端补码） |
| `0x03` | FLOAT | `float` | **无** | 8 | IEEE 754 双精度浮点数（小端） |
| `0x04` | STRING | `str` | **有 (uint64)** | **变长** | UTF-8 编码字符串 |
| `0x05` | ARRAY | `list` / `tuple` | **有 (uint64)** | **变长** | 有序元素列表 |
| `0x06` | OBJECT | `dict` | **有 (uint64)** | **变长** | 键值对集合 |
| `0x07` | BLOB | `bytes` | **有 (uint64)** | **变长** | 原始二进制数据 |
| `0x08` | DECIMAL | `Decimal` | **无** | 16 | 高精度小数（int64 + uint64） |

---

## 4. 类型格式详解

### 4.1 固定长度类型（无长度字段）

#### NONE (0x00)
```
+--------+
|  0x00  |
+--------+
```
- **总大小**: 1 字节

#### BOOL (0x01)
```
+--------+--------+
|  0x01  |  value |
+--------+--------+
```
- **value**: 1 字节，`0x00`=false，`0x01`=true
- **总大小**: 2 字节

#### FLOAT (0x03)
```
+--------+--------+--------+--------+--------+--------+--------+--------+--------+
|  0x03  |  double (IEEE 754, 小端)                                               |
+--------+--------+--------+--------+--------+--------+--------+--------+--------+
```
- **总大小**: 9 字节

#### DECIMAL (0x08)
```
+--------+--------+--------+--------+--------+--------+--------+--------+--------+
|  0x08  |  int64 (有符号, 小端)        |  uint64 (无符号, 小端)                  |
+--------+--------+--------+--------+--------+--------+--------+--------+--------+
```
- **整数部分**: 8 字节有符号整数
- **小数部分**: 8 字节无符号整数
- **组合**: `f"{int_part}.{frac_part}"`
- **示例**: 123 + 456 → `"123.456"`；-123 + 456 → `"-123.456"`
- **总大小**: 17 字节

---

### 4.2 变长类型（带 uint64 长度字段）

所有变长类型在类型标记后都跟一个 **uint64** 长度字段（小端序）。

#### NUMBER (0x02)
```
+--------+--------+--------+--------+--------+--------+--------+--------+--------+
|  0x02  |  length (uint64)             |  数据 (变长)                           |
+--------+--------+--------+--------+--------+--------+--------+--------+--------+
```
- **长度**: 数据的字节数（uint64）
- **数据**: 小端字节序，补码表示（支持正负数）
- **编码规则**:
  - 正数：直接转小端字节
  - 负数：补码表示（最高位为 1）
- **示例**: `-12345` → `[0xC7, 0xCF, 0xFF, 0xFF, 0xFF, 0xFF, 0xFF, 0xFF]`

#### STRING (0x04)
```
+--------+--------+--------+--------+--------+--------+--------+--------+--------+
|  0x04  |  length (uint64)             |  UTF-8 数据 (变长)                    |
+--------+--------+--------+--------+--------+--------+--------+--------+--------+
```
- **长度**: UTF-8 编码后的字节数（uint64）
- **数据**: UTF-8 编码字符串

#### BLOB (0x07)
```
+--------+--------+--------+--------+--------+--------+--------+--------+--------+
|  0x07  |  length (uint64)             |  原始二进制数据 (变长)                |
+--------+--------+--------+--------+--------+--------+--------+--------+--------+
```
- **长度**: 数据的字节数（uint64）
- **数据**: 原始二进制数据

---

### 4.3 复合类型

#### ARRAY (0x05)
```
+--------+--------+--------+--------+--------+--------+--------+--------+--------+
|  0x05  |  total_len (uint64)          |  elem_count (uint64)                  |
+--------+--------+--------+--------+--------+--------+--------+--------+--------+
|  元素1 (TLV)                                                                    |
+--------+--------+--------+--------+--------+--------+--------+--------+--------+
|  元素2 (TLV)                                                                    |
+--------+--------+--------+--------+--------+--------+--------+--------+--------+
|  ...                                                                            |
+--------+--------+--------+--------+--------+--------+--------+--------+--------+
```
- **total_len**: 所有元素 TLV 的总字节数（uint64）
- **elem_count**: 元素个数（uint64）
- **元素**: 每个元素都是完整的 TLV
- **语义**: 作为**键**时 → `tuple`；作为**值**时 → `list`

#### OBJECT (0x06)
```
+--------+--------+--------+--------+--------+--------+--------+--------+--------+
|  0x06  |  total_len (uint64)          |  pair_count (uint64)                  |
+--------+--------+--------+--------+--------+--------+--------+--------+--------+
|  键1 (TLV)                                                                      |
+--------+--------+--------+--------+--------+--------+--------+--------+--------+
|  值1 (TLV)                                                                      |
+--------+--------+--------+--------+--------+--------+--------+--------+--------+
|  键2 (TLV)                                                                      |
+--------+--------+--------+--------+--------+--------+--------+--------+--------+
|  值2 (TLV)                                                                      |
+--------+--------+--------+--------+--------+--------+--------+--------+--------+
|  ...                                                                            |
+--------+--------+--------+--------+--------+--------+--------+--------+--------+
```
- **total_len**: 所有键值对 TLV 的总字节数（uint64）
- **pair_count**: 键值对个数（uint64）
- **键**: 完整的 TLV，不能是 OBJECT (0x06)
- **值**: 完整的 TLV，可以是任意类型
- **键约束**: 数组作为键时转为元组，OBJECT 不能作为键

## 5. 类型标记汇总

| 标记 | 类型 | 长度前缀 | Python 类型（键） | Python 类型（值） |
|------|------|---------|-----------------|-----------------|
| 0x00 | NONE | 无 | `None` | `None` |
| 0x01 | BOOL | 无 | `bool` | `bool` |
| 0x02 | NUMBER | uint64 | `int` | `int` |
| 0x03 | FLOAT | 无 | `float` | `float` |
| 0x04 | STRING | uint64 | `str` | `str` |
| 0x05 | ARRAY | uint64×2 | `tuple` | `list` |
| 0x06 | OBJECT | uint64×2 | **禁止** | `dict` |
| 0x07 | BLOB | uint64 | `bytes` | `bytes` |
| 0x08 | DECIMAL | 无 | `Decimal` | `Decimal` |

## 7. 实现注意事项

### 7.1 整数编码
- NUMBER 使用变长小端补码，支持任意精度
- 正数：直接编码，长度按实际字节数
- 负数：补码表示，长度比正数多 1 字节（预留符号位）

### 7.2 键的约束
- OBJECT 不能作为键（会抛出类型错误）
- ARRAY 作为键时自动转为 `tuple`（保证 hashable）
- 其他类型作为键时保持不变

### 7.3 长度字段
- 所有变长类型使用 **uint64**（8 字节）长度前缀
- 支持最大 2⁶⁴-1 字节的数据

### 7.4 字节序
- **小端序** (Little-Endian)
